# Weather App 🌤️

A responsive weather app built with React.js and Vite. Search any city to see live temperature, humidity and wind speed.

🔗 **[Live Demo](https://weather-app-ucraft.netlify.app)**

## Features
- Search weather by city name
- Live temperature, humidity and wind speed
- Dynamic weather icons
- Fully responsive (desktop and mobile)

## Tech Stack
React.js, Vite, CSS, OpenWeather API
